# Rekenmachine Practicum (GitHub Samenwerking) Door alleen Ian

## Beschrijving

Een eenvoudige Python rekenmachinemodule (`calculator.py`) met een uitvoeringsscript (`main.py`). Dit project is in duo-teams gebouwd om te oefenen met GitHub-samenwerking, feature branches, pull requests, code reviews, het oplossen van merge conflicts en issue tracking.

## Medewerkers (Collaborators)

* **Student A** – Repository-beheerder, `multiply` feature branch, code reviews en conflictresolutie.
* **Student B** – Partner, `subtract` feature branch, code reviews en conflictresolutie.
